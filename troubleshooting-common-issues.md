# Troubleshooting Common Issues

Work through these checks before opening a support ticket. Restart RedM after each change.

### Cannot connect

1. Confirm that Red Dead Redemption 2 and RedM are updated.
2. Close RedM completely and restart your computer.
3. Check for a server status announcement in the community Discord.

### Slow loading, stutter, or missing textures

* Close background applications that use CPU, memory, or disk space.
* Confirm that your system meets the [faq.md](faq.md "mention").
* Lower graphics settings if performance remains unstable.

### Controls or interface do not work

Open your RedM settings and confirm the relevant keybind. Check [keybinds.md](keybinds.md "mention") for the server controls.

### Still need help?

Open a support ticket. Include the error text, when it happened, and screenshots or clips when available.

For inventory help, see [dont-see-option-to-split-items.md](dont-see-option-to-split-items.md "mention").
