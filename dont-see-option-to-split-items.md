# Don't see option to split items

### Split an inventory stack

The split option only appears for eligible stacked items. A single item cannot be divided.

1. Open your inventory with `I`.
2. Select the item stack you want to divide.
3. Use the available split action and choose the amount.

### If the option is missing

* Confirm that you selected a stack with more than one item.
* Some items cannot be split by design.
* Close and reopen the inventory if the menu does not refresh.

If an eligible stack still cannot be split, capture a screenshot and open a support ticket.
